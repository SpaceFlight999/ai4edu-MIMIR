# MIMIR 透明字标

以效果图1.png为参考，保留 MIMIR 装饰字、智者、书本、生命树、凯尔特绳结与水纹构图，去除外围英文标语及羊皮纸背景。原始参考文件未修改。透明成品通过内置 imagegen 的背景提取模式生成；生成式抠图不是原始像素的无损提取，细线与纹理可能有局部差异。

- `mimir-original-transparent.png`：透明 PNG 成品。
- `artwork.svg`：嵌入透明 PNG 的 SVG 容器，不是重新绘制的矢量字形。
- `motion-runtime.mjs`：局部图案动画与交互源代码；`interactive.mjs` 为构建产物，复用现有透明 PNG，不生成或替换图案。
- `demo.html`：明暗背景与大小尺寸预览。
- `build.mjs`：从透明 PNG 同步静态资源和互动组件。

保留 primary/night/mono/white 旧导出路径以兼容调用，当前全部使用同一浅色线描渐变图案。PNG 输出为 960×464。主页面字标桌面宽 285px，随屏幕缩放，窄屏约 171–209px，非图案位置保留返回首页动作；点击书本或河流时保留对应加速动作，老者始终轻摆。系统减少动态设置会停止循环动效，失焦、页面隐藏或离开视口会暂停。

图像编辑提示：仅提取原 MIMIR 装饰图案，背景和字母间隙透明，去除外围英文及边框，保留原构图、人物、书本、树、绳结、水纹和配色，不简化或重新设计。

## 提示词2：图案常态动画与点击交互

| 部位 | 常态 | 点击后（4.2 秒后恢复） |
| --- | --- | --- |
| 老者 | 胡须 4.8 秒轻摆 | 保持轻摆，不添加手势或闪光 |
| 书本 | 每 3.6 秒从右向左翻一页，连续循环 | 翻页周期缩短为 1.1 秒 |
| 三棵树 | 4.4 / 3.5 / 5.2 秒错峰摇动 | 保持常态 |
| 五个字母内纹样 | 固定轮廓和配色，取消位移、倾斜、缩放及渐变流动 | 保持常态 |
| 水流与水滴 | 水纹连续流动，水滴错峰落下 | 水纹周期从 2.4 秒缩短至 0.6 秒，水滴同步加速 |

鼠标与触屏可点击书本或河流加速；老者点击不增加捋须或闪光效果。聚焦字标后，左右方向键选择图案，回车或空格触发现有动作，Escape 清除选择并恢复首页按钮行为；独立预览保留可聚焦热点。支持减少动态、窗口失焦/页面隐藏/离开视口暂停和组件卸载清理。主页面共用一份内嵌 PNG，避免重复存储相同素材。

## 页眉排版

成长工作空间与版本信息独立于字标，位于右侧主页面顶部栏最右下角，距页面右边缘 4px、栏底 3px。页眉保留边缘留白；版本由 growth/package.json 在构建时自动写入，当前为 v0.12.10。

字标在上一版尺寸基础上缩小 5%。撤回额外的页眉 padding、gap 和 1180px 导航换行覆盖，原有 style.css 与 navigation.css 不作修改，仅保留字标自适应和右下角版本信息定位。

导航标题统一为加粗字重，五个入口使用等宽等高布局并与字标居中对齐，副标题维持常规字重；窄屏保留横向滚动。翻页仅从右向左推进，循环切页时暂隐活动页，静态书页底图持续保留，不再把同一页反向拉回。

## 首页紧凑布局

首页上方留白收紧为 20px，短窗口为 10px，四个入口卡片采用 96px 最小高度；状态信息与卡片保持 12px 间距。在内容可容纳时优先一屏展示，超小窗口仍允许滚动而不裁切内容。已检查带成长记录的 1280×720、1366×768、1440×720 和 1000×768 窗口。

首页整体留白：仅在首页为右侧整体区域设置顶部 12px、底部 16px 留白，内容区保留额外下沿间距。顶部标识下移，完整学习记录与四入口仍按正常顺序排布；已验证 1536×960、1440×900、1366×768 和 1280×720 桌面窗口无多余滚动。

## 浅色线描与泉水线条

字标从原始透明 PNG 提取外轮廓和内部细线，以雾蓝、灰紫、浅灰渐变表现。保留人物、书本、树、绳结和水纹构图，降低实心填充；轮廓适当加粗，第一个 M 下方补强 V 形折线，老者下方结饰仅淡化，不再挖透明间隙。源 PNG 不修改。静态资源和互动组件使用同一线描规则。

渐变配色保持静态，字形轮廓固定。仅保留翻书、树木、水流（水纹与水滴）及胡须轻摆；关闭渐变流动、扫光、冠饰闪光、悬停聚光、点击波纹和捋须手势。减少动态与失焦暂停继续生效。

首页泉水仅加粗原线条：圆环 1.35px、水流虚线 1.8px、水面弧线 1.2px、外轨道边线 2px。原有图案、颜色、透明度、5/12 虚线节奏和 16 秒水流动画保持原样。
