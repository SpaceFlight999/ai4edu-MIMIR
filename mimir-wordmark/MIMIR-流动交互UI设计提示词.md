# MIMIR 艺术字流动交互 UI 设计提示词

> 使用方式：将下方“完整提示词”交给负责 UI 设计与前端实现的 AI，并提供本目录的 SVG 资源。
> 当前交付是设计提示词文档；以下动效、组件与验收项是后续实现要求，不代表现有资源已经具备这些能力。

## 完整提示词

你是一名擅长品牌字标、微交互和 SVG 动效的 UI 设计师兼前端工程师。请基于现有 MIMIR 艺术字，设计并实现一个具有适度流动性、可以跨项目复用的交互式品牌字标组件。

### 1. 工作位置与目标

在以下目录内开展工作：

```text
D:\Xiaorui Wang\AI+竞赛资料\v0.12.9\mimir-wordmark
```

先阅读 `README.md`、`build.mjs`、`index.mjs`、`package.json`，查看 `preview.png` 和 `svg/` 中的现有资源，然后复用真实字形路径。

核心目标：**让 MIMIR 像一股持续流动的智慧之泉，未交互时已有轻盈的生命感，靠近时回应，点击时产生一次明确、优雅的能量涟漪。**

需要清晰区分三种体验：

| 状态 | 触发方式 | 视觉关键词 | 用户感受 |
| --- | --- | --- | --- |
| 默认 / idle | 页面加载完成，鼠标不在字标区域 | 缓慢流光、微弱呼吸 | 字标本身正在流动 |
| 悬停 / hover | 鼠标进入并在字标区域移动 | 局部聚光、柔和跟随 | 字标感知并回应靠近 |
| 点击后 / activated | 鼠标点击、触屏轻点或键盘激活 | 涟漪传播、短暂提亮、自然回落 | 一次可辨识的唤醒反馈 |

默认状态必须持续、无缝地运动，不能只在首次加载时播放一次，也不能依赖鼠标移动后才开始。点击反馈必须在松开后继续播放，不能只做按住时的缩放。

### 2. 视觉方向：智慧之泉 · 静谧灵光

保留现有自绘衬线字形、M 的尖谷结构、R 的曲线与两个 I 上方的菱形装饰。气质偏安静、理性、有学术感，同时有轻微的水流和灵光意象。

使用现有品牌颜色：

| 用途 | 颜色 |
| --- | --- |
| 深雾蓝 | `#3D506C` |
| 雾蓝 | `#728BAE` |
| 灰紫 | `#7B769D` |
| 暖金点缀 | `#B79768` |
| 浅色展示背景 | `#F7F6F2` |
| 深色展示背景 | `#202B3E` |

浅色主题以 `mimir-primary.svg` 为基础；深色主题以 `mimir-night.svg` 的配色为基础。单色与反白资源继续保留，作为低干扰和静态回退版本。

设计重点落在**字形内部的光色流动，以及两枚菱形的轻微呼应**。背景最多提供很淡的环境光，不应让效果变成“静止 Logo 加动态背景”。完整字标必须始终清晰、可读，不使用液化变形、夸张扭曲、碎裂、浓重霓虹或大面积粒子。

### 3. 默认状态：没有鼠标参与，也在流动

设计一层缓慢移动的宽柔光带，沿字标内部从左向右连续流动。光带应裁切在字形路径内部，像柔和光线掠过温润材质，而不是锐利的扫描线或加载骨架屏。

- 主流光建议周期为 9–12 秒，强度低但在正常观看的前 3–5 秒内可以察觉变化。
- 周期起止保持视觉连续；循环边界不得突然闪回、跳色或停顿。
- 主体轮廓、字距和基线保持稳定；流动感主要来自内部光色，避免五个字母分别上下跳动。
- 两枚暖金菱形以约 5–7 秒周期轻微呼吸，可错开约四分之一周期；亮度缓变，可选极小位移，但不旋转、不闪烁。
- 字标主体与菱形是两个主要动态层级，其余装饰保持安静。
- 字标从首帧起完整可见，不采用逐字出现或长时间淡入。

该状态应适合长时间停留在学习或研究产品中，能感知到生命感，同时不持续争夺阅读注意力。

### 4. 悬停状态：光随靠近，字形保持稳定

鼠标进入字标及其合理留白区域后，在默认流光之上叠加局部聚光响应。

- 在约 200–300ms 内温和提高局部亮度；基础慢流光继续运行，不重置播放进度。
- 字形内出现一个宽而柔的光晕，其中心跟随指针，带约 100–180ms 的平滑追随感，不能机械瞬移。
- 指针在某个字母附近时，该区域略为明亮；光晕跨越字母间隙时平滑过渡，不因没有命中字母路径而反复进出 hover。
- 较靠近指针的菱形可轻微提亮，与文字保持统一响应。
- 允许可选的微弱整体偏移；在展示宽度 480px 时上限为 2px，且不能改变布局或移动点击命中区域。无需强行加入倾斜或 3D 效果。
- 鼠标移出后用约 350–500ms 平滑收回聚光，恢复默认强度；基础流动保持连续。
- 仅组件区域显示适当的可点击光标，不替换系统鼠标指针，不追踪整个页面。

悬停效果应明显比默认状态更聚焦，而不是简单把所有动画加速。

### 5. 点击后状态：点亮一次智慧涟漪

点击代表“唤醒字标的一次视觉回应”。默认只触发视觉反馈，不擅自跳转页面、播放声音、弹窗或执行其他业务。需要业务动作时由宿主显式接入回调，并保持原有动作语义。

一次激活动效建议总时长约 1.4–1.8 秒，以 1.6 秒为初始调试值：

| 阶段 | 建议时间 | 效果 |
| --- | --- | --- |
| 即时响应 | 0–120ms | 点击附近出现细小亮点；可选整体缩至 0.99 后回弹，保持位置稳定 |
| 涟漪扩散 | 120–900ms | 柔光从点击位置向两侧穿过字形内部，形成一次有方向的传播 |
| 灵光呼应 | 300–1000ms | 两枚菱形短暂提高亮度，文字光色呈现一次温和的峰值 |
| 回归平静 | 900–1600ms | 扩散层淡出，回到当前应有的 hover 或 idle 状态 |

补充规则：

- 可以在字标周围加入至多一道低透明度外扩细涟漪，但它是辅助手段；核心反馈必须在文字内部可见。
- 点击不同位置时，涟漪起点随之变化；通过键盘激活时起点使用字标中心。
- 光色峰值保留笔画边缘，避免变成整片纯白、遮住字形或形成刺眼闪光。
- 点击后不进入永久“已选中”状态，不留下一直发亮或持续高速运行的效果。
- 连续点击不排队叠加：视觉动画期间合并重复激活，不创建多套涟漪；本次结束后可再次触发。
- 视觉动画的合并策略不擅自吞掉宿主业务事件；业务回调按宿主约定处理。

### 6. 状态衔接与边界行为

将基础慢流光与临时交互效果分层管理，交互层优先级为 `activated > hover/focus > idle`。减少动态效果的偏好和用户暂停设置优先于所有动画。

明确处理以下情形：

1. 鼠标移入：从当前 idle 相位进入 hover，不从头播放。
2. 鼠标移出：平滑撤去聚光，继续 idle。
3. 点击后鼠标仍在区域内：完成激活动效后回到 hover。
4. 点击后鼠标已离开：完成激活动效后回到 idle。
5. 动画过程中指针跨过字母间隙：保持同一个稳定命中区域，避免闪烁。
6. 动画过程中窗口失焦或页面不可见：停止不必要的运算；恢复可见时清理过期激活效果并平滑恢复，不补播积压动画。
7. 组件销毁：释放监听器、计时器、动画和帧循环。

组件外层的命中区域和布局尺寸保持稳定，动态层不能拦截指针事件或造成布局偏移。

### 7. 响应式、触屏与可访问性

- 保持原始 `viewBox="0 0 960 260"` 与宽高比，不拉伸字形；保证两枚菱形和局部光效不被错误裁切。
- 重点适配 160px、240px、480px、720px 四档显示宽度，并在 375px 宽视口下检查无横向溢出。
- 小尺寸版本减少光效层次与运动幅度；大尺寸展示可以更细腻，但仍服从同一套视觉语言。
- 触屏没有 hover，进入页面仍播放默认慢流光，单次轻点直接触发激活，结束后回到 idle；不要求先点一下进入悬停。
- 整个字标作为一个交互控件，使用合适的原生语义。纯视觉激活采用 button；若宿主明确指定导航用途，则使用链接并遵守其键盘行为。
- button 可通过 Tab 聚焦、Enter 或 Space 激活，设置准确的可访问名称，例如“MIMIR，播放灵光效果”；装饰层不重复朗读。
- 键盘聚焦呈现与 hover 相当的聚光提示，同时有清晰的焦点轮廓；临时动效不使用表示持久切换的 `aria-pressed`。
- Web 点击区域高度至少 44 CSS px；不得通过改变字标比例凑尺寸，可扩展外层留白。
- 响应 `prefers-reduced-motion: reduce`：关闭持续流光、跟随位移、缩放和扩散，用静态高亮区分状态，激活提示短暂保留后恢复。
- 提供可访问的“暂停动效 / 开启动效”控制，并支持宿主接管；暂停后以静态反馈保留交互辨识度。该控制不嵌套在字标按钮内。
- 默认持续流动适用于正常动态偏好且未暂停的情况；可访问性降级是有意的例外。

### 8. 实现与跨项目复用要求

请先确认宿主技术栈。当前资源包只有 SVG 和 ESM 资源导出，不应据此假定为 React 项目。

- 优先采用内联 SVG、局部样式与轻量 JavaScript；没有现成框架时，提供可在普通 HTML 页面使用的实现。
- 保留原始路径数据；允许将现有两个菱形所在的复合路径拆成独立图层，但不能改变最终轮廓。
- 将基础字形、流光、聚光和激活涟漪拆成清晰的图层；利用共享字形遮罩或裁切实现内部光效。
- 现有部分字母使用平移变换，需正确统一光效坐标，确保流光能穿过整个单词，不在每个字母内分别重启。
- 每个实例的渐变、遮罩、裁切等 SVG ID 必须唯一，同页多个字标互不串色、串状态。
- 保持原有 SVG、PNG 和静态导出兼容；通过新增交互组件与命名导出扩展能力，不移除已有 `primary`、`night`、`mono`、`white` 导出。
- 样式限制在组件作用域内，不污染宿主页面，不依赖全局字体、固定背景或在线资源。
- 提供主题、宽度、动效开关及可选激活回调等必要配置，不堆砌无用参数。
- 默认透明底，能够直接放入现有浅色与深色界面；展示页背景与组件本体分离。
- JS 未加载或动效不支持时，仍展示完整静态字标。
- CSS 适合处理循环与透明度变化，指针跟随按帧合并更新；避免每次 pointermove 都触发组件整体重渲染。
- 优先使用 transform 和 opacity；如需更新渐变或遮罩，限定绘制范围。避免全屏模糊、复杂液体模拟、持续生成粒子或不必要的 WebGL 和大型依赖。
- 目标是在常见设备上平滑运行；实际验证后报告表现，不把“目标 60fps”写成未经测量的结论。

### 10. 验收标准

- [ ] 页面加载后不移动鼠标，观看至少 12 秒：字形内部持续流动，能够观察到无缝循环，不只是背景在动。
- [ ] 默认状态没有夸张漂浮、跳动、闪烁或字形扭曲，MIMIR 始终可辨识。
- [ ] 鼠标移入、移动、移出：局部聚光与指针有关，字母间隙不引起状态抖动，移出后自然回落。
- [ ] 点击并松开后：完整播放一次内部涟漪，与悬停状态清晰不同；点击不同位置具有不同起点。
- [ ] 点击后分别停留、移出：正确返回 hover 或 idle，基础慢流光不跳帧重启。
- [ ] 快速连续点击 10 次：没有无限叠加、动画排队、异常闪光或结束后无法恢复。
- [ ] 触屏单次轻点和键盘激活均可使用，焦点可见，动效不会改变命中区域。
- [ ] 暂停动效和系统减少动态效果设置均生效，仍可通过静态反馈区分状态。
- [ ] 深浅主题、小尺寸、窄视口和多个实例均正常，没有裁切、变形、样式污染或 SVG ID 冲突。
- [ ] 保留原有资源导出与静态回退，卸载组件及页面不可见时不会持续运行无用动画。

最终呈现应让人感到：**MIMIR 在安静地流动，因靠近而聚光，被轻触后泛起涟漪，再回到平静。**
