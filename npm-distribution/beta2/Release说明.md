# MIMIR 0.12.11-beta.2

本次 beta2 更新优化了 Windows 安装与首次使用体验：

- 改进长路径提取，兼容 Windows PowerShell 的旧版路径处理方式，减少因依赖目录过深而导致的解压失败。
- 缩短安装临时目录和程序版本目录。
- 通过 npx 安装后自动创建桌面「MIMIR」快捷方式，使用程序原有的双线 M 托盘图标。
- 纳入更新后的使用说明，并说明程序、个人资料及升级入口的位置。
- 从 0.12.10 升级时继续使用原资料目录，现有成长功能版本保持 0.12.10。

安装前请准备 Windows 10/11 x64 与 Node.js 24 或更新版本，然后在 PowerShell 中执行：

```powershell
npx.cmd --registry=https://registry.npmjs.org/ @spaceflight99/mimir@0.12.11-beta.2
```

首次运行会下载约 938 MiB 的运行包。安装后可直接双击桌面图标启动。

已完成本机长路径回归、安装器测试、完整运行包提取、后端启动与快捷方式检查；尚未在截图中出现问题的另一台电脑实测。
