# DSH 成长与学习接入 · 0.8.0

成长层通过包内 DSH 的真实 Agent 会话运行模型，复用原默认模型与凭据。范围为成长方案生成、阶段回望、即时交流、成果评价和研究摘要；共享方案的 AI 适配也复用方案生成入口。本地示例仍需明确选择。

## 使用入口

1. 保存编辑，从原托盘退出后台，再双击根目录 `Start MIMIR.cmd`。左上角应显示 `v0.8.0`。
2. 在原有模型设置中配置凭据并选择可用默认模型，无需把 Key 写到成长配置或聊天里。模型选择本身不表示凭据已经通过验证。
3. 成长配置最后一步选择“MIMIR 为我设计”，生成候选并预览确认；完整学习页点击“获取 AI 成果反馈”；即时交流点击“与 MIMIR 交流”。阶段回望和前沿研究中的 AI 操作也使用同一模型路由。

模型缺失、凭据错误、网络故障、结果格式错误、超时和步数上限会显示对应提示。可以检查原模型设置后重试，或主动选择本地示例、仅记录反馈、仅保存成果与自评。失败不会自动覆盖当前方案或替换为示例。模型调用费用由使用者的账户承担。

## Agent 可以做什么

| 工具 | 输入与返回 | 保存边界 |
| --- | --- | --- |
| `growth_learning_context` | 本次请求已经提供的画像、目标或成果上下文 | 不读取其他文件、任务或附件 |
| `growth_course_unit` | 已收录课程及单元的官方来源、导学、练习和完成标准 | 不返回练习答案键 |
| `growth_robotics_check` | 长度、角度、预测坐标；返回理想二连杆模型计算与误差 | 不创建学生验证记录或完成记录 |

工具由模型按需调用。核心课、公开课和题目来源仍由已有目录确定，资料检索使用既有检索接口。Agent 不自行编造链接，也不执行系统或文件操作。

工具与提示词只在本次 Agent 中注册。完整教练提示词关闭插值，抑制动态运行环境上下文；不提供全局工具。允许列表守卫拒绝未授权工具。每次最多四个推演步骤、八次允许的工具执行，最多 8192 输出 token，输出文本另有 60000 字符上限，超时两分钟。结束、失败和取消均释放本次 Agent。

模型只产生待校验结果：方案必须满足资源、课程、先修、方向和时间约束；成果评价必须逐项匹配原标准；研究摘要必须引用本次检索条目。通过校验后才保存，并检查数据版本，防止旧响应覆盖较新记录。方案切换仍须学生确认，任务完成仍须满足原学习条件。

## 开发与验收

`growth/src/dsh-agent.mjs` 管理独立 Agent、工具、事件、取消和清理；`model.mjs` 保留业务提示词与结果校验；`host.mjs` 注入原模型选择、DSH Agent、工具与提示词服务。会话消息使用当前 v4 支持的生产者来源 `mimir-growth`。成功记录附带 provider、model、engine、sessionId、steps 和工具状态，便于追踪。

68 项单元检查通过。原生验收直接启动包内 DSH，通过本机 Messages HTTP 测试服务验证真实注册、推演、工具执行、鉴权失败、非法结果、四步上限、取消、并发版本冲突和重启，共 9 组场景、22 次受控请求。研究数据为明确标记的 Atom 测试数据。测试没有替换 DSH Agent 注册器，也没有调用真实在线模型；付费调用为零，个人学习数据库哈希保持一致。日常体验 16 组、运动学专题 8 组原生与浏览器回归检查也通过。

这些检查证明当前运行包的接线与状态边界，不代表已验证在线凭据、模型教学质量、真实学生体验或其他设备。真实模型效果需要使用已配置凭据另行验收。完整证据见 [验收记录](validation.md)。
