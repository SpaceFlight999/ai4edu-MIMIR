# MIMIR 参赛演示与试用准备

## 项目介绍草稿

MIMIR 智慧之泉面向本专科学生，把分散的科研、竞赛、课程与兴趣学习连接成可调整的成长路径。学生配置目标、侧重、目标深度与可用时间，成长教练据此设计阶段方案，串联论文阅读、项目设计、课程带练和前沿探索。方案先由学生确认，学习过程留下成果与自评，阶段回顾围绕学习目的和实际困难重新安排下一步。首个示范场景为智能制造专业的机器人与智能产线。方案支持共享和个性化再适配，帮助学生从「得到建议」走向「完成目标并持续选择」。

关键词：个性化成长、AI Agent、智能制造、阶段复盘、学习闭环。

## 约十分钟演示脚本

| 时间 | 演示动作 | 核心说明 |
| --- | --- | --- |
| 0–2 分钟 | 打开智慧之泉大入口，按六步选择目的、四方向和深度 | 先选择再表达，每一步支持确认与回退 |
| 2–4 分钟 | 选择基础与时间，进入独立候选页，逐项预览并确认 | 配比是侧重；定性目标和完成标准使目标可执行 |
| 4–6 分钟 | 世界树固定下一步、勾选小步自查，点知识节点预览两连杆任务，再答题、提交成果并确认完成 | 从地图进入具体行动；自查、成果和完成是不同记录 |
| 6–8 分钟 | 选项式记录卡点，诺伦回望记录「更喜欢控制」，调整配比，确认下一阶段 | 用实际困难与目的追问修订；旧地图、清单和成果仍可查 |
| 8–9 分钟 | 从密米尔之林进入方案库，Star 收藏、导出和重新适配 | 共享路径，也尊重个体差异；收藏目前属于本机 |
| 9–10 分钟 | 返回森林入口进入独立论坛，展示原论文导读入口 | 专业模块逐步接入；讨论演示与在线社区分清 |

无真实模型配置时，选择本地示例，并明确说明它是规则示例。连接模型后，演示真实 AI 生成、交流或成果反馈；不要用本地示例冒充在线 Agent 的输出。模型网络失败时保留当前有效方案，可以解释候选确认与失败保留机制。

0.4.0 功能演示可从首页或左侧四个入口开始：课程与知识图谱 → 点概念 → 公开课程 → 保存问答；竞赛工作台 → 历年题 → 四步报告 → 带入目标；前沿研究 → 联网获取 Top 5 → 日期与原文 → 带入阅读目标；兴趣探索 → 选方向 → 开始当前兴趣目标。然后进入世界树完整学习页，展示机械臂角度预测或兴趣信息分类，再提交成果、明确完成、回答用途追问。前沿列表真实联网，无模型也能查看；中文概览须连接模型。开始录制前检查页面版本号为 v0.4.0。

建议三名团队成员分别以科研、项目、课程偏好试用，但不要把团队试用描述成大样本效果验证。先记录基线，再执行至少一个任务和一次复盘；使用 `pilot-record.csv`，如实记录失败与修改意见。

## 提交前仍需完成

1. 使用参赛模型账户完成真实调用与现场网络检查。
2. 三位同学实际试用，补齐试用记录和允许展示的成果。
3. 另一台 Windows 电脑运行启动器，验收首次凭据、托盘退出和数据目录。
4. 依据最终赛道二 OPC 提交表填写团队 / 场景 / 产品价值与商业假设；不要把尚未验证的付费意愿写成市场事实。
5. 录制演示视频并检查截图与材料中无密钥或认证 URL。代码补丁包不包含原始大运行包，另按平台限制选择提交方式。

后续价值验证可以围绕「是否更清楚下一步」「任务是否适合时间」「目的追问是否帮助取舍」「复盘是否确实改变安排」展开。成本记录应区分模型调用、资料准备与人工支持，当前没有宣称学习成绩、获奖率或收入提升。
