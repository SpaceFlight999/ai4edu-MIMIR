# 世界树：从方案阅读到学习行动

本版让用户每次只面对一个工作视图：行动清单、知识地图、阶段路径。顶部提示下一步和当前完成进度，任务展开及地图探索时摘要收成短条，把空间留给操作。阶段路径是远期成果预览，实际双周阶段通过方案记录回看。

## 0.3.0 已实现

| 交互 | 学生的动作 | 保存及联动 |
| --- | --- | --- |
| 小步自查 | 打开目标，逐项勾选完成标准 | SQLite 保存；可筛选推进中的任务，不代替成果或完成 |
| 下一步 | 接受可开始任务建议，或固定自己的一个目标 | 按前置、周次、侧重与卡点推荐；个人选择可清除 |
| 知识地图 | 点概念，看用途及知识联系，预览或进入关联任务 | 四方向 12 个概念；状态汇总关联任务的两周记录 |
| 卡点反馈 | 选择概念、时间、资源或其他困难，补充一句 | 保存到任务；当前阶段的 AI 复盘和交流可以读取 |
| 学习简记 | 在任务面板写摘要，或进入完整学习页 | 两处共享草稿；保存简记保留已有成果文字 |
| 成长反馈 | 显式确认目标完成，撤回，按方向查看进展 | 完成环与枝条实时变化；关联目标全部完成后节点才变色 |
| 路径探索 | 点击远期阶段，看预期成果，返回任务或进入回望 | 预览不改方案；历史清单、地图和成果保持只读 |

地图的知识联系来自教学目录，不是强制任务顺序。进度来自学习记录，不表示已经掌握；学生仍需用成果与目的判断是否继续深入。地图支持方向聚焦、缩放、内部横向平移和键盘箭头导航；窄屏展开目标后使用单独面板。

## 后续可验证的想法

1. **阶段成果架**：从完成的节点直接打开论文笔记、解题过程和验证成果，以可回看的作品替代奖章。先接真实附件与原模块成果接口。
2. **够用 / 深耕选择**：完成同一分支的一组目标后，给出目的相关的两个选择和一条追问，形成复盘候选，确认后再改深度。
3. **方法对比与反例卡**：概念节点提供一个反例或两种方法，让学生解释适用边界；验证答案后给下一步建议。
4. **计划试演**：选择“本周只有三小时”或“课程临时加量”，预览时间与侧重变化，并由学生确认新候选。
5. **同路人的支线**：从知识节点进入相关论坛话题及可 Star 的共享路径。在线社区上线前不展示虚构热度或同学进度。

这些是后续设计方向，本版未实现。优先用真实同学的操作观察验证是否更清楚下一步、是否更容易留下成果，再增加交互复杂度。
