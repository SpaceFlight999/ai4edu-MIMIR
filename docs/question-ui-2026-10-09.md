# 0.12.6 提问选区与问答历史

选中论文原文并点击「提问」，选区使用独立的临时高亮层，按选中行的实际矩形绘制。输入问题、点击空白处、操作输入控件和缩放不会取消高亮；翻到其他页时暂时隐藏，回到原页继续显示。发送有效问题时取消临时高亮和浏览器文字选区，原提问范围仍保留用于发送和追问；切换论文时重置选区，避免跨论文误用。

问答按生成时间从新到旧排列，默认折叠。原生 `details/summary` 支持键盘展开，展开后显示完整回答、原文证据和保存笔记等已有操作。问题标题和生成时间可直接查看；选区原文单独保存和显示，不再混入问题标题。每项旁边的「删除」同时移除本机问题与回答，刷新和重启不会恢复，后续问答上下文与导出也不包含已删除记录。导读和批注的原排序保持不变。

删除接口 `conversation-delete` 先核对当前论文，再按该论文中的问答编号删除，不能用另一篇论文的编号删除记录。已完成的对应内存任务结果也会移除；原论文、导读、批注和已提交工作台建议使用各自存储。

123项单元检查和11组实际后台／Edge场景通过。覆盖输入、真实背景点击、缩放、发送清理、选区范围保留、最新问答在上、键盘折叠、跨论文删除拒绝、导出排除删除内容，以及刷新和重启不恢复。18次请求均使用本机模拟模型，付费调用为0；测试阶段个人数据库和论文记录哈希保持一致。报告见 `artifacts/question-smoke.json` 和 `artifacts/unit-tests-0.12.6.json`。
