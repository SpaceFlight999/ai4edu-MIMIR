本轮依据《提示词3》的六项产品要求修改现有工作区，不改变原生运行包版本（Mimir 0.12.0-beta.1）。成长层版本为 0.9.0。

## 使用入口

保存当前编辑，从系统托盘退出 MIMIR，重新双击根目录 `Start MIMIR.cmd`。左上角应显示 `v0.9.0`；仅刷新网页不能重新加载后端模块。

| 要求 | 当前行为 |
| --- | --- |
| 原研究页面显示与切换模型 | 输入区显示具体模型 ID，点击打开 Mimir 设置 → 模型；保存后立即同步显示 |
| 智慧之泉标题与布局 | “你想成为怎样的自己？”保持一行，字号随内容宽度调整，360～1440 像素验收无横向溢出 |

## 自己补充内容

专业方向、学习目标、学习目的、核心课、公开课、竞赛与历史题、研究方向、兴趣方向均支持“其他”。每类最多 50 项，名称最多 80 字，说明最多 1200 字。课程、竞赛可填可选来源地址，仅接受不含登录信息的 HTTP/HTTPS 地址。相同类别的同名条目不会重复创建。

专业和目的可直接选为配置值，学习目标可加入目标列表。核心课、公开课及兴趣补充可带入个人成长目标；保存来源供后续设计参考，不会凭名称自动编造课程正文、练习或官方认证。竞赛补充可打开实际工作台，编辑、保存并导出自己的分析。研究和兴趣方向可选用于 arXiv 检索；建议填写明确的英文研究关键词，联网结果取决于检索条件与上游服务。

目标最多 12 条，每条最多 1200 字。旧版本只有 `profile.goal` 的档案按单条目标读取，保留原内容；新版同时保存 `profile.goals` 和兼容的合并文本。所有目标进入 DSH 方案请求，提示模型覆盖目标并说明时间冲突与取舍，候选仍需用户确认。

## 模型与凭据

原“研究”的模型入口、Mimir 设置 → 模型、前沿研究的模型区共用原生 `agentDefaultModel` 选择。选择目录中的供应商和模型，填入该供应商的 Key，点击“保存模型与 Key”。留空只保存模型、保留已有凭据；成功后清空输入框，接口仅返回是否已配置，不返回 Key。

凭据通过 DSH 的配置描述与凭据服务保存，成长 SQLite 和请求重放记录不存 Key。当前 DeepSeek 入口可编辑；其他供应商是否可编辑取决于其原生配置注册，界面会明确显示只读或缺少入口。外部环境提供的只读凭据不能在此覆盖。

原启动器的初始 Key 只在原生凭据尚未配置时初始化。更换 Key 后重启，旧启动器记录不会覆盖新 Key。切换不同模型时清除不适用的旧推理档位，同一路由保留原档位。进行中的任务沿用其已启动会话，新任务读取保存后的路由。

本轮通过本机受控模型服务验证了真实 DSH 注册器、Agent 执行和 HTTP 请求的模型及鉴权值。保存成功不代表真实供应商已接受该 Key；真实在线授权、余额和生成质量尚未验收。

## 实现与验证

- `growth/src/custom-choices.mjs`：八类补充、来源校验和安全检索条件。
- `growth/src/model-settings.mjs`：原生目录、凭据映射、模型选择与串行保存。
- `growth/client/models.js`：研究入口、共享模型控件及原生设置窗口桥接；只保留一个可见保存入口。
- `growth/client/configuration.js`：多目标配置；`customization.css`：响应式标题与补充、模型样式。
- `scripts/install-growth.mjs`：安装成长覆盖层及启动凭据初始化修正。
- `scripts/smoke-customization.mjs`：独立合成目录，覆盖八类补充、三目标、浅深色与窄屏、实际模型请求及重启持久化。

75 项单元检查、9 组新增原生／浏览器场景、9 组 DSH Agent 场景通过。浏览器异常为零；个人数据库哈希保持一致，付费模型调用为零。独立复审发现的原生服务访问与旧目标长度兼容问题已修复。验收明细与边界见 [验收记录](validation.md)，截图和 JSON 位于 `artifacts/`。
