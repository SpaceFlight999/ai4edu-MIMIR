# 提示词5 · 导航、学习层级与确认日期

版本：0.11.0；日期：2026-10-08。

## 本轮变化

- 左上角图标与「Mimir 科研工作空间」是第一个可点击入口，点击进入研究；下一项是带原创泉流 SVG 的「智慧之泉 / 我的成长计划」。侧栏移除课程、竞赛、前沿、兴趣四个快捷入口，保留「研究 / 论文 / 文稿」插件工具。五大功能继续在成长空间顶部导航。
- 启动默认进入智慧之泉，不挂载研究项目目录、新建研究和项目搜索；点击研究或 Mimir 品牌入口后展示研究环境。返回成长、论文或文稿时收起研究目录。智慧之泉顶部的 MIMIR 字标采用衬线字形与泉流标记，可点击返回首页。
- 「确认后，有什么变化？」成为独立折叠区，默认展开，收起不影响任务预览与确认按钮。展开后桌面双栏、窄屏单栏；按调整目标、新增目标、延续记录、保留到历史排序。同类变化按个人成长配比从高到低，再按任务周次排列；完全相同时保留原顺序。
- 完整重新配置、复盘修订、导入适配后的方案，以实际确认时刻作为双周起点；轻回顾为七天后，阶段结束为十四天后。单门课程加入或课程内调整仍保留当前阶段日期，进入下一阶段则重新计时。世界树日期使用上海时区显示；不迁改已确认的历史日期。
- 「单一主题深入学习」「核心课路线」使用统一的大标题和小号说明，分别展开自己的内容，彼此不联动收起。核心课下的推荐与补充、所选课程、公开课程资料、推荐习题、扩展检索均有相应的层级折叠区。
- 更多公开课默认显示两门，可展开全部十门并再次收起；机器人知识图谱也有独立入口。原有课程详情、主题学习、补充添加与编辑、检索、确认候选等功能继续使用原来的数据和接口。
- 推荐练习题干统一 16px，选项 15px、逐行排版；课程检查、专题和机器人先修检查采用同一阅读标准。折叠区有展开状态与键盘支持，收起内容设置 inert；动效遵循减少动态效果偏好。

## 启动与验收

当前工作区的 `runtime/` 已安装 0.11.0。保存正在编辑的内容，从原实例托盘退出后，双击 `Start MIMIR.cmd`。顶部成长空间字标下应显示 `v0.11.0`；仅刷新页面不会重新加载旧后台。

验证文件：

- `artifacts/unit-tests-0.11.0.json`：96 项单元检查，包含重新确认日期、课程日期保留和变化排序。
- `artifacts/prompt5-smoke.json`：9 组真实包内后台 / Edge 场景，覆盖侧栏优先级与按需项目目录、独立折叠及 Enter 操作、全部公开课、练习入口、候选双栏与排序、实际确认日期、窄屏、深色与重启。
- `artifacts/installed-growth-check-0.11.0.json`：33 个实际安装覆盖文件的大小和 SHA-256。
- `artifacts/prompt5-*.png`：本轮合成验收截图。

本轮使用独立合成数据，个人学习数据库 SHA-256 未改变，未调用在线模型；AI 候选和本地候选共用变化展示。模型教学质量和其他设备安装不属于本轮验收范围。旧版验收与截图保留为历史证据，不能当作 0.11.0 重跑结果。交付包保留历史 JSON 报告，只收录本轮截图；旧截图仍留在原工作区。

## 源码与维护

导航修改在 `growth/client/app.js` 和 `growth/overrides/workbench/client.js`；原宿主侧栏使用已声明的 `sidebar.brand.name` 插槽承载智慧之泉，避免修改额外的宿主包。折叠和排序在 `growth/client/daily.js`，学习目录在 `library.js`、`curriculum.js`、`study.js`，样式集中于 `prompt5.css`，确认日期在 `growth/src/domain.mjs`。

构建、安装后可使用包内 Node 依次运行 `scripts/check-unit-tests.mjs`、`scripts/smoke-prompt5.mjs` 和 `scripts/check-installed-growth.mjs`。浏览器验收会启动并关闭独立测试后台与无界面 Edge。早期的浏览器脚本含旧侧栏和旧目录布局断言，当前版本的本轮导航与折叠验收使用 `smoke-prompt5.mjs`。
