# 0.12.1：取消研究输入字符预算

按用户“输入预算取消，自己完成修改”执行。

## 修改

- 删除“高级设置：调用预算”和输入字符上限字段。
- 删除研究阶段的总输入字符拦截、按论文均分配额，以及依配额截断正文和遗漏证据的逻辑。
- 初次读取和补充读取均保留明确授权范围内全部已解析正文与可定位证据。缺页、视觉内容未充分提取等真实解析情况仍记录。
- 旧客户端传入的 `maxInputChars` 字段仅作兼容接收，忽略且不保存；新界面与研究工具参数均不再提供该设置。
- 区分原文缺少证据、引用定位失败、模型返回格式错误、模型输出过长和供应商上下文容量不足，避免将调用前失败描述为模型结果未通过校验。
- 保留 15 分钟时限、取消、最多六次模型调用、输出长度约束、项目与版本授权、逐字引用定位及语义复核。

本次取消的是综合研究与写作的应用侧输入字符预算。普通导读既有分段处理方式继续使用；PDF 提取能力与供应商自身上下文容量仍适用。

## 验证

102 项单元检查通过；错误提示分类新增回归。实际 MIMIR 后台、真实 PDF 解析、DSH 传输和隔离 Edge 完成 9 组场景。

长输入使用 17 页及 42 页合成 PDF，提取正文分别为 75,696 和 187,596 字符、证据分别为 748 和 1,848 条。检查每页末行仍在快照，全部证据数量与解析 API 一致，未出现排除页、截断页或遗漏证据，保存的任务不含输入字符上限。分析、写作与复核请求均超过原 200,000 字符可设置上限，本机模拟服务收到的 HTTP JSON 约 193 万字符（含来源元数据），三阶段完成并通过引用校验。

回归同时覆盖导读与回答历史、原文批注定位及删除、跨页签草稿、名称修改、写作提交、关闭页签保留、失败清理、运行中取消／删除、窄屏／深色和重启恢复。27 次模型请求均使用本机模拟服务，付费调用为零；浏览器异常为零，个人学习数据库与论文数据文件 SHA-256 未改变。

按 code-review 自审输入兼容、授权读取、逐字引用校验和错误分类。37 个安装覆盖文件核对通过，完整原运行包基线沿用历史证据。未调用个人供应商验证真实输出质量。

报告：`artifacts/unit-tests-0.12.1.json`、`artifacts/input-budget-smoke.json`、`artifacts/installed-growth-check-0.12.1.json`；更新包：`artifacts/MIMIR-growth-0.12.1.zip`。

## 生效

修改已安装到本项目运行目录。保存当前编辑后，通过托盘退出并使用 `Start MIMIR.cmd` 重启，加载新后台；只刷新浏览器不能替换已驻留的旧后台。旧失败记录保留其发生时的原因，重新生成的任务使用新逻辑。
