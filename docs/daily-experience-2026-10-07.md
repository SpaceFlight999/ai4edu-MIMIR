# 日常使用体验 · 0.6.0

本轮承接 10.6 优化路径的路径2，以及用户提供的提示词2。保留既有核心课、候选确认、成果历史与 to-do 勾选逻辑。

## 续学与保存

首页从当前方案的未完成任务中挑选最近的学习记录，显示实践位置、步骤、保存时间与上次安排；有独立浏览器草稿时提示待恢复。展开其他学习可直接切换任务。

学习页手动保存实践输入、成果与自评草稿、已选答案和目的反馈。SQLite 中的保存内容支持退出重开。另以 localStorage 自动备份编辑，显示“浏览器已备份 · 尚未保存到成长记录”，供同一浏览器、同一地址刷新恢复。两种保存方式有不同提示；浏览器备份不能宣传成已提交到成长记录。

恢复前可以预览、选择恢复或放弃。服务端更新不等于独立草稿已保存；待恢复时离开重入、历史只读、失败后继续编辑、重试旧请求均需保留已有内容。备份按方案、任务与页面 ID 隔离，最长保留30天，每任务最多8份并行备份，达到上限或浏览器存储受限时明确提示手动保存／导出。恢复另一页草稿复制到自己的页面槽，不共用正在编辑的槽。

导出的 JSON 是供学生自行保留、回看或复制文字的草稿文件，本轮未提供导入入口。更换浏览器、原生实例地址或设备后，使用已手动保存的成长记录；未保存内容应提前导出。

## 按时间安排动作

从当前实践位置开始：10分钟最多一小步，20分钟最多两步，40分钟最多三步；剩余不足时只列实际剩余动作。所有分步工作坊适用。

| 任务 | 10分钟从第一步开始 | 20分钟从第一步开始 | 40分钟从第一步开始 |
| --- | --- | --- | --- |
| 论文 | 定位材料与目的 | 加上问题与方法对照 | 再加原文依据与局限 |
| 竞赛 | 明确模块接口 | 加上正常流程与异常恢复 | 再加验证方法 |
| 课程 | 导学判断 | 加上检查练习与解释 | 再加应用场景与检查方法 |
| 兴趣 | 选择场景与原因 | 加上信息职责分类 | 再加小问题与实验方法 |

完成本次范围后进入成果整理；手动保存不会自动标记完整目标完成。时间是本次安排，未引入倒计时或自动能力评分。课程完整条件和先修检查继续由服务端验证。

## 错误恢复

| 原因 | 恢复方式 |
| --- | --- |
| 本机服务连接中断 | 保留编辑，导出草稿，恢复后台后重试同一请求；成功回调保留失败后新增的编辑 |
| 记录版本变化／任务失效 | 刷新保存记录并对照草稿，再手动保存；不自动用旧请求覆盖新记录 |
| 授权失效／后台缺少功能 | 导出草稿，重新打开或从托盘退出后启动对应实例 |
| AI 不可用／输出无效 | 检查原模型设置，再手动发起；成果反馈可明确选择仅保存自评 |
| 课程未完成 | 保留小步成果，继续剩余实践；不绕过完整条件 |
| 输入不完整 | 显示具体缺少的字段，允许先保存草稿 |

## 提示词2落实范围

核心课保持八门路线默认可见，并提供更多和搜索；额外公开课入口覆盖当前收录的10门。竞赛可查名称、年份、方向和历史题；研究和兴趣可查方向。专业方向、学习目标与学习目的使用同一搜索组件。搜索不改变当前选择，空结果可清除关键词，支持键盘、暗色与窄屏。

固定时间、状态、年级、自评和答题项维持已有选择范围。站内目录筛选与联网 arXiv 资料检索分别说明；修改检索词后清空旧结果，避免把上一组资料误认为新关键词的返回内容。

界面采用“我要学习／正在学习”“可以检查的知识点”“继续深入学习”等表达。领域词“迁移”仍保留，表示把方法用于新场景；代码 ID、评分标准、历史记录不因改文案而改变。

验收证据与未覆盖边界见 [validation.md](validation.md)。
