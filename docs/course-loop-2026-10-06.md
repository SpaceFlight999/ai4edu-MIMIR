# 0.5.0 课程学习闭环

目标：学生选择一门已有公开课程后，进入与该课程对应的学习目标，保存实践和成果，通过够用 / 深耕 / 求助生成可解释的候选，确认后继续。此次范围是上一轮提出的课程闭环及其必要的保存、恢复和差异展示。

## 数据与流程

1. 沿用现有四门课程及其官方链接，增加 MIMIR 原创小段导学、针对性练习、应用 / 深耕 / 补基础 / 迁移单元。原创内容不冒充官方讲义。
2. 课程任务引用白名单中的 `courseRef: { id, variant }`，使用 `course-study` 工作坊；`unitKey` 从课程 ID 和单元类型派生。来源地址、练习和工作坊由后端目录决定。
3. “建立课程学习候选”按当前预算替换一项课程方向任务，预览替换与延续的任务。确认前正式方案和成果不变。无课程投入时提示先配置；尚无方案时先形成初始候选。
4. 保留任务使用 `continuedFrom` 关联旧任务，确认时复制已有成果、过程、自查和卡点；旧方案中的记录仍只读。改变了来源、单元或完成标准的任务不直接继承完成状态。
5. 保存过程包括工作簿、成果草稿、答题选择和本次实践范围。10 / 20 / 40 分钟分别安排最多 1 / 2 / 3 个剩余实践块，不代表实际计时或自动完成目标。
6. 课程目标正式完成要求已保存说明、检查练习和迁移解释；保存一个小步不能代替完整完成。目的选择只记录反馈，下一步始终生成候选并要求确认。
7. 够用生成成果迁移，深耕生成比较与验证，求助生成补基础任务。已做过的同类单元优先进入不同的后续单元或下一门已注册课程。
8. 首页按最近保存的未完成学习提供继续入口；未保存离开和刷新有提醒。所有写入继续使用版本、幂等和失败不覆盖的原契约。

## 实施与验收

顺序：课程目录与任务契约 → 候选及成果延续 → 课程工作坊与保存恢复 → 界面差异 → 单元与宿主 / 浏览器验收 → 构建安装及覆盖层校验。

必须验证：线性代数练习不会进入二连杆工作坊；三个目的选择产生不同的任务；候选未确认时旧方案有效；未完成的其他任务能够延续且旧历史不变；保存草稿后刷新、重启可恢复；10 分钟的小步不能冒充完整目标；旧 0.4.0 数据可继续读取；无模型也能完成流程。

真实模型质量、学校平台、三位同学试用和另一台电脑的原生界面验收仍需相应账号、参与者和设备。本轮的自动验收使用独立合成目录。
