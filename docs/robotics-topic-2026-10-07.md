## 工作台模型与边界

连杆长度 L1、L2 以米为单位，各在 0.01～10 米；关节角使用度或弧度，分别限制在 ±180° 或 ±π。第二关节角相对第一根连杆，不能直接当作全局角。

`x = L1 cos(θ1) + L2 cos(θ1 + θ2)`

`y = L1 sin(θ1) + L2 sin(θ1 + θ2)`

服务端计算关节点、末端坐标和预测的欧氏距离误差。练习通过阈值为 0.02 米，仅用于教学检查；不表示机械臂硬件精度。工作台不包含碰撞、关节限位、动力学、弹性、标定或实物控制。导学和问答为 MIMIR 原创，官方课程通过已注册来源链接访问。

每任务最多30条验证记录；未完成时可以明确确认后删除记录，已完成目标只读。撤回完成保留记录。前端不能通过提交 passed、kind 或模型坐标来伪造验证结果；所有结果由后端重新计算。
