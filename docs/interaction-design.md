# MIMIR 0.4.0 交互闭环

首页保持智慧之泉的大入口，直接提供课程、竞赛、研究、兴趣四个入口。全局左侧栏提供相同捷径，从原论文和文稿模块也可进入。知识与实践页四个子页分别工作；全局捷径会切到指定子页。页面显示版本号，帮助区分旧实例。

## 培养与学习

六步配置 → 独立候选预览 → 明确确认 → 世界树当前阶段。打开目标先看目的与自查，再进入完整学习。完整学习按准备、实践、成果、下一步切换；实践本身分为三步，提供选择、可操作实验或工作簿，再保留自由表达。

| 方向 | 实践 | 成果 | 下一步 |
| --- | --- | --- | --- |
| 科研 | 论文来源、问题与方法、论据与局限 | 可编辑的阅读卡片 | 用于后续阅读，或继续比较方法 |
| 竞赛 | 输入输出与约束、正常流程和不同异常、指标与验证 | 设计与验证报告 | 够用、深耕或记录卡点 |
| 学习 | 机械臂角度与位置预测、实验反馈、问答、迁移解释 | 练习过程与理解 | 补先修或进入下一目标 |
| 兴趣 | 选择场景、分类感知/决策/执行信息、提出小实验 | 探索卡片 | 继续探索或停在入门深度 |

过程保存、成果保存、问答正确、自查勾选都不自动完成目标。学生明确标记完成；系统仍验证先修目标。已完成任务的工作簿只读，允许撤回完成后修改。历史阶段只读。成果保存与工作簿保存分别持久化，阶段回望读取当前阶段记录，保留历史。

完成后的固定追问先提供“够用了 / 继续深耕 / 需要帮助”，再问用途或偏好，最后允许补充。需要帮助会记录卡点，可进入与 MIMIR 的交流；继续深耕作为复盘时的配置建议。阶段复盘分目的、投入、下一步三页；调整仍需生成并确认候选，禁止悄悄更改计划。

## 内容与任务的衔接

课程概念 → 先修与课程 → 官方课程链接 → 原创练习与解释 → 保存记录 → 带入当前学习目标。

赛事推荐 → 官方历史题 / 规则 → 四步工作台 → 保存草稿 / Markdown 导出 → 带入当前竞赛目标。工作台可以自由返回修改，恢复上次步骤；它是个人实践记录，不执行代码或硬件任务。

研究方向 → 用户主动联网 → 带日期和来源的近期列表 → 原文 / 摘要 → 可选模型中文概览 → 阅读或兴趣目标。查询方向固定，缓存最长一小时，网络错误不替换成示例。模型概览必须引用实际返回的论文 ID。摘要和出版状态来自 arXiv，预印本状态明确显示。

兴趣方向 → 当前兴趣目标中的完整学习 → 场景选择和信息分类 → 小实验问题；也可直接查看对应方向近期研究。当前没有相应未完成目标时，入口提示并转到成长侧重配置，已保存内容保留。

带入目标只合并成果草稿，并打开对应学习页；必须再保存，不改变完成状态。当前首批是机器人示范，不能视为覆盖所有专业的自动课程体系。

## 模型与外部系统

模板路径、课程问答、工作台、知识自评和学习保存可独立使用。培养方案 AI、AI 成果反馈、教练交流与中文概览复用原默认模型，需要有效凭据。学校平台接口后续由用户提供后接入，当前不会假装已连接 DeepEdu2.0。Star 与论坛是各 data-home 内的本地记录。
