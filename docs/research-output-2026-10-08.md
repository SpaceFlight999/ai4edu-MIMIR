# 0.12.3：精简研究输出并显示草稿

最新失败记录为 `MODEL_OUTPUT_LIMIT`：第一次分析调用耗尽模型输出额度，JSON 未完整生成。页面因此没有可显示的结果。本轮同时处理模型生成长度、响应中的重复内容和页面展开方式。

## 修改

- `growth/overrides/host/model-output.mjs` 提供简洁生成要求：重点结论靠前，每篇至多 3 条主张、2 条方法、2 条限制和2个问题；综合草稿至多6段，保留适用条件与不确定性。复核只关注实际使用的结论和引用，避免逐条输出全部来源证据。
- 研究调用查询当前模型支持的推理强度，在支持时采用较低强度，并预留16,384个输出 token。只影响研究任务，保持全局选择不变；任务记录包含原选择和实际调用强度。不能完整结束或不能解析的 JSON 仍按失败处理。
- 完整 JSON 解析后仅去除结果列表中的完全重复项；独有文字、限定条件、未知引用和范围错误继续保留供校验。原文、页面、来源证据及解析快照不经此精简函数修改。
- `research-get` 的 `result` 视图只传回结果引用到的证据，`full` 视图保留全部证据清单。页面导出使用 `full`，保存和发布仍读取本地完整结果。
- 页面优先显示综合草稿，完成后自动滚动到结果。论文分析、读取范围和复核详情使用可折叠区域，首次展开才创建内容；重新展开不会重复添加。引用按钮显示简短原文摘要，悬停和原文跳转保留完整信息。
