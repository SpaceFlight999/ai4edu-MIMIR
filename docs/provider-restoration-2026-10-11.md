# MIMIR 0.12.10 提供商配置恢复

按用户要求恢复原版 DSH 的提供商和模型配置能力。此前 0.12.9 的官方 DeepSeek 地址和模型限制已移除；先前的功能修补、研究回复质检和提示词继续保留。

## 使用方法

重新启动 Mimir，进入“设置 → 模型 → 配置提供商”。原版编辑器支持选择第三方提供商，也支持“自定义模型 API”：填写 Provider ID、显示名称、API 地址、协议、API 密钥及模型目录，创建后点击“返回模型选择”，选定提供商和模型，再点击“保存模型与 Key”。

原版自定义协议包括 OpenAI Chat Completions、OpenAI Responses 和 Anthropic Messages；接口必须符合对应协议。Key 通过原生凭据服务保存，页面不回显已存 Key。默认 DeepSeek 配置只是可修改的初始值。已有自定义配置在启动和安装时保留，不再强制迁移。此前被旧策略改写过的选择无法凭空恢复，需要用户在页面重新选择。

## 修改范围

- 全局模型策略只负责科研回复质检，不再改写选择、路由、请求参数或限制官方地址。一次质量修正继续使用原请求的提供商和模型。
- 会话标题模块恢复原版 DSH 实现，使用会话记录的模型路由或原生显式覆盖配置。
- 模型设置增加同风格“配置提供商”和“返回模型选择”按钮，复用原生编辑器、凭据服务和适配器。主页面布局不变。
- 复用原生设置区域的所属组件及渲染权限，避免重复注册和失效的设置入口。侧栏挂载其非可视桥接组件，仅在已有设置对话框显示控件。
- 三处旧策略错误提示改为通用提供商配置提示；工作区及增长层版本更新为 0.12.10，已安装到本地 runtime。
