## 0.12.2 精简模型输入并保留真实错误类别

每页原文只发送一次，证据使用短编号和原文起止位置；模型返回后还原完整证据编号，再进行现有来源和引用校验。本机最近失败任务的请求从 1,945,133 字符降至 475,100 字符，减少 75.57%，59 页原文与 3,088 条证据全部保留；没有恢复输入预算。

模型的安全错误类别不再被通用适配错误覆盖；超时、模型参数不兼容和输出不完整分别显示具体原因。研究调用为当前思考模式保留更多输出空间，并要求简短结果。108 项单元检查、10 组实际后台／浏览器场景与 38 个安装覆盖文件验证通过。修复已安装并通过本地后台重启加载；线上复测待用户授权。详见 [精简代码和故障说明](docs/research-model-2026-10-08.md)。以下为历史版本记录。

## 现在开始体验

双击根目录的 **Start MIMIR.cmd**。首次模型凭据窗口可以选择稍后连接。智慧之泉以大入口开始，点击「开启我的成长配置」或「重新构建我的成长」，完成六步配置。在最后一步选择「先体验本地示例」，再点击「确认配置并生成方案」。这条路径不调用付费模型。

如果更新前已经打开 MIMIR，请保存当前编辑，从托盘退出后重新双击 **Start MIMIR.cmd**；只刷新浏览器不会重新加载后端模块。

当前工作区已经恢复完整运行包、安装成长模块。请从这个启动入口使用参赛版；此前自行解压的目录保留作为原包参考。

**确认新版本：**页面左上角 MIMIR 下方显示 `v0.11.0`。左侧栏首先显示 Mimir 入口，其次是智慧之泉；研究、论文、文稿作为插件入口。智慧之泉首页仍有四张学习入口卡片：

**完整学习入口：**世界树 → 点开一项目标 →「进入完整学习」。过程分为准备、分步实践、成果与反馈、下一步。论文工作坊记录来源和论据；竞赛任务设计正常流程与异常处理；课程任务有机械臂角度实验和检查问答；兴趣任务有信息分类互动。保存过程不会自动标记完成；明确完成后，可以选择“够用了 / 继续深耕 / 需要帮助”，再回答目的追问。阶段回望汇集这些选择，允许回到配比、深度和时间配置，确认候选后才更新方案。

1. 六步配置依次选择身份、目的与目标、成长侧重、目标深度、时间与基础，最后确认。各步先给选项，页面下方折叠的自定义入口保留自由表达；上一步和退出配置保留本次选择。
2. 方案进入独立预览页。分周查看任务，点击每项预览其目的、能力目标、预期成果与完成标准；可以返回配置，确认后才成为当前方案。
3. 世界树提供「行动清单」「知识地图」「阶段路径」三个视图。任务展开后逐项自查、固定下一步、保存学习简记或记录卡点；地图支持点概念、看联系、预览对应任务及进入学习。也可进入完整学习页做练习、提交成果与自评，再自行确认完成；撤回完成保留成果。
4. 诺伦回望分为目的回顾、下一步选择、反馈记录。配比调整沿用分步配置；旧方案与成果保留在历史中。随时反馈有独立交流页面。
5. 密米尔之林并列提供「方案共享」「同好论坛」子入口。方案库支持 Star 收藏、取消收藏、我的 Stars 筛选，以及 JSON / Markdown 导出、JSON 导入与重新适配。论坛独立展示话题列表与讨论页。

AI 路径复用原产品的默认模型与凭据设置，连接有效模型后才能使用。AI 失败会显示错误，不会自动替换成本地示例，也不会覆盖当前方案。模型费用由使用者的模型账户承担。

本启动入口默认使用 `data/student-1/`，不会把验收合成记录带入你的个人成长档案。成长数据在其中的 `mimir-growth/growth.sqlite`，原研究资料也使用同一 data-home。退出前等待保存结束，再从原有系统托盘选择退出；关闭网页不会停止后台。

其他试用者可使用独立数据目录：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/start-mimir.ps1 -DataHome .\data\student-2
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/start-mimir.ps1 -DataHome .\data\student-3
```

每个目录相互独立，适合分别启动试用；本版没有公共服务器上的多用户账号体系。方案库、Star 和论坛回复都保存在当前目录，Star 数量表达本机是否收藏，不是跨用户热度。备份完整数据目录前先退出相应实例。共享方案与导入预览采用字段白名单，不附带个人档案、对话和成果；任务正文可能含你主动写入的个人目标，分享前仍需预览。

不要分享 `model.secret`、`instance.json`、完整启动日志或浏览器登录数据。补丁包只包含代码、说明和合成测试截图。

## 在另一目录恢复参赛版

把补丁 ZIP 解压到一个新目录，把原始 `Mimir-0.12.0-beta.1-Windows-x64.zip` 放到该目录根部，双击 **Install MIMIR.cmd**，完成后双击 **Start MIMIR.cmd**。恢复会创建 `runtime/`，不修改原始 ZIP。

原包有少量空文件 ZIP 元数据异常：恢复脚本按清单的空文件逻辑恢复，随后检查原包 inventory 的 SHA-256。可运行以下命令检查基线及当前安装模块：

```powershell
& .\runtime\system\node\node.exe scripts/verify-runtime.mjs
```

启动后 Python 可能重建 `.pyc` 缓存；校验报告单独记录这些变化，并验证对应 `.py` 源文件仍与原包完全一致。
