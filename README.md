# MIMIR · 智慧之泉

**一个含“成长规划、学习实践、论文导读与阶段回望”的个人学习工作空间。**

MIMIR 面向希望自主安排学习与成长的学生。你可以从自己的目的、基础和可用时间出发，预览并确认学习方案，在实践中保存过程与成果，再根据体验调整下一步。首批课程与实践示例聚焦机器人与智能制造方向。

当前版本：**v0.12.10**。支持 **Windows x64**，通过 `npx.cmd` 安装和启动。

## 基本功能

- **个人成长规划**：配置目的与目标、成长侧重、目标深度、学习时间和已有基础，预览方案后自行确认。
- **课程与知识图谱**：查看核心课与先修关系，寻找公开课程、资料和实践入口，把课程候选带入个人学习目标。
- **学习与竞赛工作台**：分步记录实践、草稿、算例与成果，保存学习简记、卡点和下一步行动。
- **论文阅读与文稿整理**：导入 PDF，阅读原文、标注与提问；接入模型后使用论文导读、综合研究和文稿辅助功能。
- **阶段回望与方案分享**：回顾当前阶段、预览下一阶段调整，导出方案，或导入他人的方案重新适配。

个人成长方案用于安排自己的学习，不替代学校正式教学培养方案。

## 安装与启动

### 1. 准备环境

- Windows 64 位（x64）。
- [Node.js 24 或更新版本](https://nodejs.org/)，包含 npm 和 npx。
- 首次安装需联网访问 npm 官方源与 GitHub Releases。运行包约 **938 MiB**，解压后约 **2.23 GiB**，请预留足够磁盘空间。

不需要提前安装 MIMIR，也不需要单独配置 DSH。完整运行环境已随运行包提供，使用者无需注册 npm 或 GitHub 账号。

### 2. 执行安装启动命令

打开 Windows PowerShell，复制并执行：

```powershell
npx.cmd --registry=https://registry.npmjs.org/ @spaceflight99/mimir@0.12.10
```

如果出现 `Ok to proceed? (y)`，输入 `y` 并回车。首次执行会下载运行包、校验 SHA-256、解压并启动 MIMIR；过程中请保持窗口打开。下载和解压时间取决于网络与磁盘速度。

以后仍使用同一条命令启动，程序会复用已经安装的版本，并保留本机的学习记录。

仅安装、暂不启动时，可执行：

```powershell
npx.cmd --registry=https://registry.npmjs.org/ @spaceflight99/mimir@0.12.10 --install-only
```

### 3. 安装的软件在哪里？

程序按当前 Windows 账户安装，默认位置是：

```text
%LOCALAPPDATA%\MIMIR-Evaluation
```

按 **Win + R**，粘贴上面的路径并回车，即可打开。通常对应：

```text
C:\Users\你的Windows用户名\AppData\Local\MIMIR-Evaluation
```

目录用途：

| 目录 | 内容 |
| --- | --- |
| `versions\0.12.10-4fb1588e98f9\runtime` | v0.12.10 的完整程序与运行环境，启动文件为 `Mimir.exe` |
| `data\0.12.10` | 此版本的个人学习记录、论文资料和本机配置 |
| `cache` | 已下载的运行包缓存 |

安装时所在的 PowerShell 工作目录不影响上述安装位置。不同 Windows 账户各自使用自己的安装与数据目录；卸载前如需保留学习资料，请先备份 `data\0.12.10`。

### 4. 创建桌面快捷方式（可选）

安装成功后，在桌面空白处右键，选择 **新建 → 快捷方式**。

“对象的位置”填写：

```text
C:\Windows\System32\cmd.exe /k npx.cmd --registry=https://registry.npmjs.org/ @spaceflight99/mimir@0.12.10
```

点击“下一步”，名称填写 **MIMIR**，再点击“完成”。以后双击快捷方式即可启动；命令窗口会保留，方便查看启动信息或报错。

## 现在开始体验

### 1. 首次打开与模型配置

首次启动时，可选择稍后连接模型，先体验本地示例。进入 **智慧之泉**，点击 **开启我的成长配置**；已有方案时，可选择 **重新构建我的成长**。

如需使用 AI 功能，在 MIMIR 的 **设置 → 模型** 中选择可用的供应商和模型，填写自己的 API Key，并按界面提示保存。AI 功能需要连接有效模型，调用费用由使用者的模型账户承担。

首次配置可在最后一步选择 **先体验本地示例**，再点击 **确认配置并生成方案**。本地示例路径不调用付费模型。

### 2. 从四个入口开始

| 入口 | 可以实际操作的功能 |
| --- | --- |
| 课程与知识图谱 | 查看 8 门核心课及先修建议，按基础和记录推荐公开课、检索资料及练习；确认课程候选后学习和保存 |
| 竞赛工作台 | 查看推荐理由和官方来源，选择历年题或规则工作台，分步填写读题、设计、测试和交付，保存草稿、导出报告、带入竞赛目标 |
| 前沿研究 | 选择方向与 Top 5 / 10，联网获取 arXiv 近期结果，查看日期、摘要和原文；接入模型后生成中文概览，带入论文阅读目标 |
| 兴趣探索 | 选择吸引你的研究方向，开始当前兴趣目标中的场景探索、信息分类、小实验，或跳转对应方向的近期研究 |

资料检索与 arXiv 查询需要联网。arXiv 结果可能包含预印本，中文概览用于辅助筛选，请结合原文核对内容。

### 3. 完成成长配置与方案预览

六步配置依次选择 **身份、目的与目标、成长侧重、目标深度、时间与基础**，最后确认。各步先给选项，页面下方折叠的自定义入口保留自由表达；返回上一步或退出配置会保留本次选择。

生成的方案先进入独立预览页。你可以分周查看任务，点开每项了解其目的、能力目标、预期成果与完成标准，也可以返回修改配置。**明确确认后，候选方案才成为当前方案。**

### 4. 在世界树中持续学习

世界树提供 **行动清单、知识地图、阶段路径** 三个视图：

- **行动清单**：展开任务，逐项自查、固定下一步，保存学习简记或记录卡点。
- **知识地图**：点开概念、查看联系，预览对应任务并进入学习。
- **阶段路径**：查看当前阶段的目标与任务安排，结合自己的进度调整行动。

**完整学习入口：世界树 → 点开一项目标 → 进入完整学习。**

完整学习分为 **准备、分步实践、成果与反馈、下一步**。论文工作坊记录来源和论据；竞赛任务整理正常流程与异常处理；课程与专题任务记录学习过程、算例验证、成果报告和应用分析；兴趣任务包含场景探索与信息分类互动。

**保存过程不会自动标记完成。** 请先保存草稿与成果，再按任务当前的完成条件明确确认。完成后，可以选择 **够用了 / 继续深耕 / 需要帮助**，并回答目的追问。撤回完成会保留已有成果。

不同课程和专题的完成条件以当前界面为准。任务完成状态用于记录学习进度，不等同于已经掌握相关知识。

### 5. 论文阅读与文稿整理

从论文学习相关入口进入 **论文导读**，可导入多个 PDF，在顶部页签之间切换。阅读时可以选择原文进行高亮、批注与提问，并通过标题导航定位内容。

接入模型后，可按页面提示进行导读或基于原文提问。使用综合研究与写作时，选择相应论文、确认研究授权范围，勾选或填写思考点，再查看生成的草稿及来源依据。

需要整理成文稿时，可将内容送入文稿工作台。请先预览修改建议和原文对照，再选择接收或拒绝，并保留自己的判断与修改。AI 生成的表述和引用仍需结合原文核对。

### 6. 使用诺伦回望调整下一步

诺伦回望分为 **目的回顾、下一步选择、反馈记录**。阶段回望会汇集学习过程中的选择和反馈，允许回到配比、深度和时间配置，预览调整后的候选方案。

**确认候选后才更新方案**，旧方案与成果保留在历史中。随时反馈也有独立交流页面，可记录当前感受、卡点和新的方向。

### 7. 在密米尔之林分享方案

密米尔之林提供 **方案共享** 和 **同好论坛** 两个子入口。

方案库支持 Star 收藏、取消收藏、我的 Stars 筛选，以及 JSON / Markdown 导出。收到他人的方案 JSON 后，可以导入、预览并按自己的基础与目标重新适配。

论坛可查看话题列表和讨论页。**当前方案库、Star 和论坛回复保存在本机，尚不是跨设备同步的公共社区。** 分享给他人时，请导出方案文件；分享前检查正文是否包含自己填写的个人目标或其他隐私内容。

## 保存、退出与备份

- 编辑后请使用页面提供的保存功能，并等待保存完成；浏览器自动草稿不能代替正式保存。
- 退出时，先保存编辑，再从原有 MIMIR 系统托盘菜单退出。仅关闭网页不会停止后台程序。
- 如需备份，先退出对应实例，再复制完整的 `%LOCALAPPDATA%\MIMIR-Evaluation\data\0.12.10` 目录。换电脑或 Windows 账户后，模型凭据可能需要重新配置。
- 不要公开分享完整数据目录、API Key、`model.secret`、`instance.json` 或浏览器登录资料。

## 常见问题

**需要单独安装 DSH 吗？**

不需要。发布的运行包已经包含 DSH、MIMIR 和成长模块。

**没有 API Key 能用吗？**

可以先使用本地示例、学习记录、算例验证等入口。AI 生成、论文问答与研究概览等功能需要连接有效模型；资源检索仍需要联网。

**AI 请求失败会发生什么？**

界面会显示错误。AI 失败不会自动替换成本地示例，也不会覆盖当前方案；请根据提示检查网络、模型配置或服务状态后重试。

**为什么安装后找不到桌面图标？**

当前安装器不会自动创建桌面快捷方式。可以继续使用上述命令启动，或按“创建桌面快捷方式”一节手动添加。

**下载源码 ZIP 后能直接运行吗？**

源码仓库不包含完整运行环境。普通使用者请优先使用上面的 `npx.cmd` 命令安装；开发者可查阅 [开发与历史版本说明](README.development.md) 及 [开发交接说明](HANDOFF.md)。
